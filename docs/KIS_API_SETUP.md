# KIS Open API 설정 가이드

## 계좌번호 형식 안내

KIS Open API에서 사용하는 계좌번호는 **10자리** 형식입니다.

### 계좌번호 구성
```
[8자리 계좌번호] + [2자리 상품코드]
예시: 1234567801
```

### 계좌번호 찾는 방법

1. **KIS 영웅문 HTS/MTS 로그인**
2. **계좌 정보 확인**
   - HTS: 상단 계좌번호 표시
   - MTS: 메인화면 계좌번호 표시

3. **계좌번호 형식 변환**
   ```
   화면 표시: 12345678-01
   API 입력값: 1234567801 (하이픈 제거)
   ```

### 상품코드 설명

| 상품코드 | 설명 | 용도 |
|----------|------|------|
| 01 | 종합계좌 | 일반적인 주식거래 계좌 |
| 02 | 위탁계좌 | 특별 관리 계좌 |

**대부분의 경우 `01`로 끝납니다.**

### 환경별 계좌번호

#### 실전투자 환경 (`TRADING_ENV=real`)
- 실제 계좌번호 사용
- 실제 자금이 움직이므로 주의 필요

#### 모의투자 환경 (`TRADING_ENV=virtual`)
- 모의투자 전용 계좌번호 사용
- KIS에서 발급받은 모의투자 계좌번호

### .env 파일 설정 예시

```env
# 실전투자 예시
TRADING_ENV=real
KIS_ACCOUNT_NUMBER=1234567801

# 모의투자 예시  
TRADING_ENV=virtual
KIS_ACCOUNT_NUMBER=9876543201
```

### 주의사항

⚠️ **보안 주의사항**
- 계좌번호는 민감한 개인정보입니다
- `.env` 파일을 Git에 커밋하지 마세요
- 코드 공유 시 계좌번호를 마스킹하세요

⚠️ **환경 설정 주의사항**
- 실전투자와 모의투자 환경을 혼동하지 마세요
- 실전투자 테스트 시 소액으로 먼저 테스트하세요

### 계좌번호 검증

프로그램에서 계좌번호 유효성을 자동 검증합니다:

```python
# 자동 검증 규칙
- 길이: 정확히 10자리
- 형식: 숫자만 허용
- 구성: 앞 8자리(계좌) + 뒤 2자리(상품코드)
```

### 문제 해결

#### 계좌번호 오류가 발생하는 경우

1. **길이 확인**: 10자리인지 확인
2. **하이픈 제거**: `-` 문자 제거
3. **환경 확인**: 실전투자/모의투자 환경 일치 확인
4. **권한 확인**: 해당 계좌의 API 접근 권한 확인

#### 자주 하는 실수

❌ **잘못된 형식**
```
12345678-01  (하이픈 포함)
123456780    (9자리)
12345678     (8자리)
```

✅ **올바른 형식**
```
1234567801   (10자리, 하이픈 없음)
```

### API별 계좌번호 필요 여부

| API 유형 | 계좌번호 필요 | 비고 |
|----------|---------------|------|
| 인증 (OAuth2) | ❌ | 앱키/시크릿만 필요 |
| 해외주식 현재가 | ❌ | 공개 정보 |
| 해외 뉴스 | ❌ | 공개 정보 |
| 해외주식 잔고 | ✅ | 개인 계좌 정보 |
| 매매 주문 | ✅ | 개인 계좌 정보 |

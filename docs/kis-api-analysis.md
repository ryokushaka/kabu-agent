# KIS Open API 해외주식 데이터 분석

## 요구사항 vs API 기능 매칭 분석

### ✅ 구현 가능한 기능

#### 1. 총자산
- **API**: `inquire_balance` (해외주식 잔고)
- **구현 방법**: output1에서 총 평가금액 조회
- **데이터**: USD/KRW 환산 총자산

#### 2. 자산 구성 (미국 주식(%), 현금(%))
- **API**: `inquire_balance` (해외주식 잔고)
- **구현 방법**: 
  - 보유 주식 총 평가금액 vs 외화예수금 비교
  - 비중 계산하여 퍼센테이지 산출

#### 3. 섹터별 분포(%)
- **API**: `inquire_balance` + `search_info` (상품기본정보)
- **구현 방법**:
  - 보유 종목별로 섹터 정보 조회
  - 종목별 평가금액과 섹터 매칭하여 비중 계산

### ⚠️ 부분 구현 가능한 기능

#### 4. 일일 수익률(%)
- **API**: `inquire_period_profit` (기간손익)
- **구현 방법**: 
  - 일별 기간손익 조회로 수익률 계산
  - 실시간 당일 수익률은 현재가 대비 계산 필요
- **제한사항**: 당일 실시간 수익률은 별도 계산 로직 필요

#### 5. 전체 자산 추세 (일별 자산 총액 변화)
- **API**: `inquire_period_trans` (일별거래내역) + `inquire_balance`
- **구현 방법**:
  - 일별 거래내역과 현재 잔고 정보를 조합
  - 과거 특정 시점의 총자산은 재계산 필요
- **제한사항**: 과거 시점별 총자산 스냅샷은 API에서 직접 제공되지 않음

## 주요 API 상세 정보

### inquire_balance (해외주식 잔고)
- **기능**: 보유 종목별 잔고, 평가금액, 손익 정보
- **제공 데이터**: 
  - 종목별 보유수량, 평균매수가, 현재가
  - 평가금액, 평가손익
  - 외화예수금

### inquire_period_profit (기간손익)
- **기능**: 지정 기간 동안의 손익 정보
- **제공 데이터**:
  - 기간별 실현손익, 평가손익
  - 매매수수료, 제세공과금
- **제한사항**: 일별 세분화된 수익률 계산 복잡

### inquire_period_trans (일별거래내역)
- **기능**: 지정 기간의 매매 거래내역
- **제공 데이터**:
  - 매수/매도 내역
  - 거래금액, 수량
- **제한사항**: 과거 총자산 스냅샷 없음

## 구현 권장사항

1. **1단계**: 기본 정보부터 구현 (총자산, 자산구성, 섹터분포)
2. **2단계**: 부분 구현 가능한 기능들 개발 (일일수익률, 자산추세)
3. **3단계**: 확인이 필요한 항목들에 대한 추가 조사 후 구현 여부 결정

## 데이터 보완 방안

확인이 필요한 기능들의 경우:
- 자체 데이터 저장소 구축하여 일별 스냅샷 저장
- 외부 시장 데이터 API와 조합하여 보완
- 사용자 정의 계산 로직 구현

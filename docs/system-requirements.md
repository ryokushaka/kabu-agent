# 해외주식 포트폴리오 관리 시스템 요건정의서

## 1. 프로젝트 개요

### 1.1 프로젝트명
**해외주식 포트폴리오 관리 시스템 (Overseas Stock Portfolio Management System)**

### 1.2 개발 목적
- KIS Open API를 활용한 사용자 해외주식 포트폴리오 실시간 조회 및 분석
- 다양한 투자 지표 제공을 통한 투자 의사결정 지원
- 관리자 기능을 통한 효율적인 시스템 운영

### 1.3 프로젝트 범위
- **대상 시장**: 미국 주식시장 (NASDAQ, NYSE, AMEX)
- **사용자**: 일반 투자자, 시스템 관리자
- **데이터 소스**: 한국투자증권 KIS Open API

### 1.4 주요 기능
- 실시간 포트폴리오 조회 및 분석
- 엑셀 파일 내보내기 기능
- 관리자 시스템 운영 기능

---

## 2. 시스템 아키텍처

### 2.1 전체 구성도
```
[사용자] ←→ [Web Interface] ←→ [Backend API] ←→ [KIS Open API]
                                      ↓
                              [Database/Cache]
```

### 2.2 기술 스택
- **Frontend**: React.js, TypeScript
- **Backend**: Python FastAPI
- **Database**: PostgreSQL
- **Cache**: Redis
- **File Export**: OpenPyXL
- **Authentication**: JWT

## 3. 기능 요구사항

### 3.1 사용자 포트폴리오 기능

#### 3.1.1 포트폴리오 대시보드 (FR-001)
**우선순위**: High  
**설명**: 사용자 해외주식 포트폴리오 종합 현황 표시

**상세 기능**:
- 총자산 표시 (USD/KRW)
- 일일 수익률(%) 표시
- 전일 대비 손익 금액 표시
- 보유 종목 수 표시
- 자산 구성 차트 (주식/현금 비중)

**입력**: 사용자 계좌 정보  
**출력**: 대시보드 화면  
**KIS API**: `inquire_balance`

#### 3.1.2 보유 종목 상세 조회 (FR-002)
**우선순위**: High  
**설명**: 보유 종목별 상세 정보 조회

**상세 기능**:
- 종목별 보유수량, 평균매수가, 현재가
- 종목별 평가금액, 평가손익, 수익률
- 종목별 비중(포트폴리오 대비 %)
- 정렬/필터링 기능 (수익률, 금액, 종목명 등)

**입력**: 사용자 계좌 정보  
**출력**: 종목 리스트 테이블  
**KIS API**: `inquire_balance`, `search_info`

#### 3.1.3 섹터별 분석 (FR-003)
**우선순위**: Medium  
**설명**: 포트폴리오의 섹터별 분산 현황 분석

**상세 기능**:
- 섹터별 투자 비중 파이차트
- 섹터별 평가금액 및 수익률
- 섹터별 종목 리스트

**입력**: 보유 종목 정보  
**출력**: 섹터 분석 차트 및 테이블  
**KIS API**: `inquire_balance`, `search_info`

#### 3.1.4 수익률 분석 (FR-004)
**우선순위**: Medium  
**설명**: 다양한 기간별 수익률 분석

**상세 기능**:
- 일일 수익률 표시
- 최근 1개월/3개월/1년 수익률 추이 차트
- 기간별 최고/최저 수익률 표시

**입력**: 사용자 계좌 정보, 조회 기간  
**출력**: 수익률 차트 및 통계  
**KIS API**: `inquire_period_profit`, `inquire_period_trans`

#### 3.1.5 자산 추세 분석 (FR-005)
**우선순위**: Medium  
**설명**: 포트폴리오 자산 변화 추이 분석

**상세 기능**:
- 일별 총자산 변화 라인차트
- 기간 필터링 (1개월/3개월/1년)
- 투자 입출금 내역 표시

**입력**: 사용자 계좌 정보, 조회 기간  
**출력**: 자산 추세 차트  
**KIS API**: `inquire_period_trans`, `inquire_balance`

#### 3.1.6 AI 포트폴리오 진단 (FR-014)
**우선순위**: High
**설명**: Gemini AI를 활용한 포트폴리오 심층 분석 및 투자 조언 제공

**상세 기능**:
- 포트폴리오 구성(섹터, 종목)에 대한 AI의 객관적 평가
- 현재 포트폴리오의 리스크 요인 분석
- 투자 성향 및 시장 상황에 따른 포트폴리오 리밸런싱 제안
- 마크다운 형식의 가독성 높은 분석 리포트 제공

**입력**: 포트폴리오 보유 종목, 섹터 비중, 수익률 현황
**출력**: AI 분석 리포트 (Markdown)
**기술**: Google Gemini Pro API

### 3.2 데이터 내보내기 기능

#### 3.2.1 엑셀 파일 내보내기 (FR-006) 
**우선순위**: High  
**설명**: 포트폴리오 데이터를 엑셀 파일로 내보내기

**상세 기능**:
- 포트폴리오 종합 현황 시트

**출력**: Excel 파일 (.xlsx)  
**기술**: OpenPyXL 라이브러리

**상세 기능**:
- 종합 분석 리포트
- 차트 및 그래프 포함

**출력**: PDF 파일  
**기술**: ReportLab 또는 WeasyPrint

### 3.3 사용자 관리 기능

#### 3.3.1 사용자 인증 (FR-008)
**우선순위**: High  
**설명**: 사용자 로그인/로그아웃 기능

**상세 기능**:
- 이메일/비밀번호 기반 로그인
- JWT 토큰 기반 인증

**입력**: 로그인 정보

**우선순위**: High  
**설명**: KIS API 계좌 정보 등록 및 관리

**상세 기능**:
- KIS API 키 등록/수정
- 계좌번호 등록/변경
- 연동 상태 확인
- 데이터 동기화 설정

**입력**: KIS API 정보  
**출력**: 연동 상태  
**보안**: API 키 암호화 저장

### 3.4 관리자 기능 (Service Operation)

#### 3.4.1 서비스 현황 대시보드 (FR-010)
**우선순위**: High  
**설명**: 서비스 운영 지표 및 현황 모니터링

**상세 기능**:
- **사용자 지표**: 총 가입자 수, 신규 가입자 추이, 활성 사용자(DAU/MAU)
- **AI 서비스 현황**: 일일 AI 포트폴리오 분석 요청 횟수, 예상 토큰 사용량
- **API 쿼터 현황**: KIS API 일일 호출량 및 한도 대비 사용률 모니터링

**입력**: 기간 설정  
**출력**: 운영 지표 대시보드

#### 3.4.2 사용자 지원 관리 (FR-011)
**우선순위**: High  
**설명**: 고객 문의 대응을 위한 사용자 정보 조회 및 상태 확인

**상세 기능**:
- **사용자 검색**: 이메일, 이름으로 사용자 검색
- **서비스 이용 상태**: KIS API 키 등록 여부, 최근 접속일, 계정 상태(정상/정지)
- **활동 이력**: AI 분석 요청 이력, 주요 에러 발생 여부 (성공/실패)

**입력**: 사용자 검색어  
**출력**: 사용자 상세 정보 및 활동 로그

#### 3.4.3 서비스 통계 분석 (FR-012)
**우선순위**: Medium  
**설명**: 서비스 이용 트렌드 및 인기 콘텐츠 분석

**상세 기능**:
- **인기 종목 랭킹**: 사용자 포트폴리오에 가장 많이 포함된 종목 TOP 10
- **기능 활용도**: 주요 기능(포트폴리오, AI 분석, 섹터 분석)별 이용 빈도

**입력**: 조회 기간  
**출력**: 통계 차트 및 랭킹 테이블

#### 3.4.4 운영 관리 (FR-013)
**우선순위**: Low  
**설명**: 서비스 공지사항 및 긴급 알림 관리

**상세 기능**:
- **공지사항 관리**: 사용자 대시보드 상단 공지사항 등록/수정/삭제
- **긴급 배너**: 시스템 점검, API 장애 등 긴급 상황 시 알림 배너 노출 설정

**입력**: 공지 내용, 배너 설정  
**출력**: 설정 적용 결과

## 4. 비기능 요구사항

### 4.1 성능 요구사항 (NFR-001)
- **응답시간**: 일반 조회 3초 이내, 엑셀 생성 10초 이내
- **처리량**: 동시 사용자 100명 이상 지원
- **가용성**: 99.5% 이상 (월 3.5시간 이내 다운타임)

### 4.2 보안 요구사항 (NFR-002)
- **데이터 암호화**: KIS API 키 AES-256 암호화 저장
- **통신 보안**: HTTPS 필수, TLS 1.2 이상
- **인증**: JWT 토큰 기반, 세션 타임아웃 2시간
- **접근 제어**: 역할 기반 권한 관리 (RBAC)

### 4.3 호환성 요구사항 (NFR-003)
- **브라우저**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **모바일**: 반응형 웹 (iOS Safari, Android Chrome)
- **파일 형식**: Excel (.xlsx), PDF

### 4.4 확장성 요구사항 (NFR-004)
- **수평 확장**: 로드 밸런서 지원
- **API 확장**: 다른 증권사 API 연동 가능한 구조
- **데이터베이스**: 파티셔닝 지원

### 4.5 운영 요구사항 (NFR-005)
- **모니터링**: 시스템 메트릭 수집 및 알림
- **로깅**: 구조화된 로그 (JSON 형식)
- **백업**: 일일 자동 백업, 7일간 보관
- **배포**: CI/CD 파이프라인 지원
